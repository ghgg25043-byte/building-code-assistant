# 虚构建筑场景练习资料

本文件由本项目独立编写，仅用于演示检索、候选定位、人工研读和工作簿导出。`DEMO-ARCH-001` 和 D-01 至 D-14 均为**虚构标识**，不是国家、行业、地方或团体标准，也不提供任何工程设计要求、尺寸、阈值或合规判断。

| 虚构条目 | 练习主题 | 使用者可补充的场景信息 |
| --- | --- | --- |
| D-01 | 建筑场景登记 | 建筑用途、使用者与练习目标 |
| D-02 | 访客通行路线记录 | 入口、到达路径与使用者需求 |
| D-03 | 屋面形式信息收集 | 屋面形式与示意模型 |
| D-04 | 屋顶设备空间记录 | 设备位置与示意图 |
| D-05 | 公共空间净高信息记录 | 房间用途与测量位置 |
| D-06 | 车辆抵达路线记录 | 出入口、周边道路与人车动线 |
| D-07 | 建筑入口信息记录 | 入口位置、使用人群与场地条件 |
| D-08 | 入口台阶信息记录 | 台阶位置、图纸编号与使用场景 |
| D-09 | 公共楼梯使用场景记录 | 楼梯用途与服务空间 |
| D-10 | 楼梯平台布置记录 | 梯段与平台的示意布置 |
| D-11 | 办公楼公共走廊信息记录 | 走廊服务空间与图纸位置 |
| D-12 | 公共卫生间布置记录 | 隔间、通道与使用者动线 |
| D-13 | 屋面排水资料收集 | 屋面做法与排水示意 |
| D-14 | 临空窗台方案记录 | 窗台位置与防护方案示意 |

这些条目只帮助演示“提出问题 → 找到虚构候选 → 记录待核对条件”。真实项目必须另行取得有权使用的现行正式规范资料，并由具备相应资格的专业人员核验。
