02 / PRODUCT LOGIC

为什么展示三种状态

产品价值不仅是“找到一个条目”，还包括让用户知道问题的哪一部分没有被当前资料覆盖。

01 / CANDIDATE

候选定位

显示虚构条目、命中原因和下一步要记录的场景信息，不生成规范结论。

02 / PARTIAL

部分覆盖

问题同时涉及已收录主题与消防专题时，保留相关候选，同时明确指出缺口。

03 / NO EVIDENCE

资料不足

当前资料不支持时停下来，不编造条号、数值或“符合规范”的判断。
