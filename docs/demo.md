# 三种可复现演示

所有返回条目均为[原创虚构练习资料](../data/demo-source.md)，只用于观察产品交互。

| 输入 | 预期状态 | 说明 |
| --- | --- | --- |
| 办公楼公共走廊的净宽要求在哪里查？ | `candidate_only` | 定位虚构 D-11；不回答真实净宽要求 |
| 办公楼公共走廊净宽和消防疏散距离有哪些要求？ | `partial` | 定位虚构 D-11，并指出消防专题未覆盖 |
| 办公楼消防疏散距离要求是多少？ | `no_evidence` | 不返回候选或数值 |

运行 `python app.py`，在首页“第一次使用”选择场景。可把 D-11 标成“列入待核对依据”，写入练习理由，设置交接状态，导出工作簿。导出的记录仍只对应虚构资料，不应进入真实工程文件。
