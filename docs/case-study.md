# 产品案例：建筑场景检索工作流原型

设计目标是让使用者从一个具体问题进入候选定位、缺口识别、人工研读和交接记录。当前用原创虚构资料验证交互流程，而非建筑专业正确性。

例如输入“办公楼公共走廊的净宽要求在哪里查”，原型定位虚构 D-11，显示匹配词、已有条件与缺失条件；若再问消防疏散距离，页面明确标出资料缺口。使用者可为候选写下研读理由并导出工作簿。所有生成记录都标明无工程效力。

已实现本地 HTTP 服务、检索与标签初筛、资料覆盖提示、可选受限模型提示、浏览器工作簿及 Markdown 导出。尚未完成真实用户访谈、建筑专业评测或商业场景验证。下一步先访谈建筑设计人员，确认高频任务、现有流程和付费意愿；引入真实资料前先解决来源许可与专业复核。
