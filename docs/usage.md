# 使用说明

本地运行 `python app.py`，访问 `http://127.0.0.1:8765`。公开版只有 14 个原创虚构练习条目，标识为 DEMO-ARCH-001、D-01 至 D-14；它们不提供任何真实规范要求或合规判断。

输入建筑场景问题并填写已知条件后，页面展示虚构候选、匹配原因、未覆盖专题和待补充信息。建筑用途只做标签初筛；城市、项目类型和设计阶段仅记录。人工备注及交接状态保存在当前浏览器，可导出 Markdown 备份。共享设备不要输入客户、图纸或个人敏感信息。

模型接口可选，默认关闭；当次勾选后仅把问题、条件及最多 3 个虚构候选主题发送到所配置服务。请核对服务商的数据处理条款。模型只能返回固定格式的 D 编号提示，不能输出工程结论。

资料结构与回归检查：`python expert_eval.py audit`、`python evaluate.py`、`python -m unittest discover -s tests -v`。开发者样本仅验证软件行为，不代表建筑专业准确率。`data/source_review_blank.csv` 是将来接入有授权真实资料时的空白审核流程示意；当前虚构条目不需专业规范复核。接入真实资料前须确认权利许可、现行版本、来源位置和专业适用性。
